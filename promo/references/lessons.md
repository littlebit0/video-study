# 교훈 (사용자가 거절한 것과 이유)

- **평범한 설명 영상 형식**: 파이프라인 도식만 있는 구성은 "그냥 설명 영상" 같다는 이유로 거절. AI 스킬 소개 릴스 형식(훅 → 고통 → 공개 → 터미널 데모 → 기능 필 → CTA)으로 바꿈.
- **기계적인 목소리 + 빠른 속도(+32%)**: SunHi를 빠르게 돌리니 기계 같다고 함. 속도는 0%(최대 +8%), 길면 문구를 줄임. 사용자가 샘플을 듣고 고르게 함(최종 InJoon).
- **흔들림·번쩍임·뿅뿅 효과음**: 훅의 화면 흔들림, 플래시, 팝/휙/클릭/딩 효과음이 거슬린다고 함. 지금은 흔들림·번쩍임·효과음 없이 페이드·슬라이드·완만한 스프링만 쓴다. 음성만.
- 사용자 문구는 그대로 살린다(예: "교수님 설명을 이해하기 어렵다? … 순식간에 마스터" → 다섯 번째 필 + 음성 한 줄).

## 주장 정책
- 사용자가 준 사실만. 성적·점수 주장, "완벽", "누구나 가능" 금지. 지어낸 숫자 금지.
- 터미널 화면은 연출이므로 "예시 화면" 라벨. 결과 클립은 실제 결과물에서, 개인정보(이름, 이메일, 학교, 교수, 과목 코드)가 없는 프레임만.
- 하트·팔로우 필은 일반 도형. 플랫폼 로고·UI 복제 금지.
- 업로드·게시·전송은 하지 않는다. 파일만 전달.
- npm install(약 400 MB)은 먼저 허락을 받는다. 브라우저는 설치된 Chrome 사용, 새로 받지 않는다.
