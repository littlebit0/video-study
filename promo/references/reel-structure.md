# 릴스 구조 (AI 스킬·도구 소개 형식)

| 구간 | 대략 시간 | 내용 |
|---|---|---|
| hook | 0–4.5 s | 질문 + 대담한 주장. 큰 글씨가 아래에서 부드럽게 올라옴 |
| pain | 4.5–8 s | 카드 3장 빠른 슬라이드 (예: 슬라이드 수백 쪽 / 녹음 몇 시간 / 시험은 코앞). 정확한 숫자를 지어내지 않음 |
| reveal | 8–10.5 s | 제품명 + 배지 + 은은한 글로우 |
| demo | 10.5–16 s | 터미널이 명령을 타이핑하고 실제 작업 흐름 단계가 하나씩 나옴, "예시 화면" 라벨, 마지막 "완성" |
| proof | 16–19 s | 노트북 프레임 안에 실제 결과 클립 2~3개 + 숫자 카운트업 |
| feat | 19–29 s | 체크 필 3~5개, 각각 사실과 일치 |
| cta | 29–34 s | 무료/오픈소스, URL, 사용법 코드박스, 작은 글씨 환경, "저장해 두고…", 하트 + 팔로우 필 + 음성 "좋아요와 팔로우 부탁드려요" |

- 컷/시각 변화는 1~2초마다. 장면 전환은 오른쪽에서 슬라이드.
- 자막: 카라오케(현재 구절 금색, 지난 구절 흰색, 다음 구절 흐리게), 높이 약 70%(top 1250, 높이 190), 최대 2줄, 62px.
- 안전 영역(릴스/숏츠 UI): 세로 10%~75%(y 192~1440), 가로 90%(좌우 54px). 핵심 내용은 y 1240 아래로 내리지 않는다(자막 자리).
- 색: 남색 #1a1a2e 배경, 금색 #f5c518, 청록 #16c79a, 빨강 #e94560. 폰트 Apple SD Gothic Neo. 모든 색은 Composition.tsx 맨 위 `C` 토큰에만 둔다(`references/design-floor.md`).
- 길이 26~35초. 음성 속도는 올리지 않고 문구를 줄인다.
