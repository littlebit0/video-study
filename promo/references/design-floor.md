# 디자인 바닥 규칙 (hallmark의 영상판)

[Nutlope/hallmark](https://github.com/Nutlope/hallmark) v2의 Floor·Reflex 규칙 가운데 세로 영상에 해당하는 것만 옮겼다. 웹 전용 규칙(focus, overflow, 1280 첫 화면, sloplint)은 영상에 맞지 않아 뺐다. 괄호 안 번호는 hallmark `references/gates.md`의 게이트 번호.

## 지키는 것 (Floor, 예외 없음)
- **색은 토큰으로만** (48): 모든 색은 `Composition.tsx` 맨 위 `C`에 둔다. 컴포넌트 안에 `#fff`·`rgba(...)`를 직접 쓰지 않는다. 검사: `grep -nE '"#[0-9a-fA-F]{3,6}"|rgba\(' src/Composition.tsx` 결과가 `C` 블록 안에만 있어야 한다.
- **손으로 그린 창 틀 금지** (47a): 터미널에 빨강·노랑·초록 점, 가짜 주소창을 그리지 않는다. "예시 화면" 라벨만 둔다. 실제 화면은 `proof` 클립으로 보여 준다.
- **이모지를 아이콘으로 쓰지 않는다** (30a): ✔·🔥·🚀 대신 `Check` 같은 SVG 도형이나 글자만.
- **지어낸 숫자·후기·로고 금지** (46a): `lessons.md`의 주장 정책과 같다.
- **보라→파랑 그라디언트 금지** (2a).

## 피하는 것 (Reflex, 이유가 있으면 예외 가능하되 보고에 적는다)
- **글로우** (29): 글자·배지 주위의 0-offset 색 번짐(`0 0 40px gold`)을 쓰지 않는다. 깊이는 아래로 떨어지는 그림자(`LIFT = 0 8px 30px`)와 밝기 차이로 낸다. 배경의 고정된 남색 방사형 그라디언트 하나는 허용.
- **꾸밈 글자** (66): 사실이 없는 버전 배지, 회전 글자, 스크롤 신호를 넣지 않는다.
- **장식용 움직임**: 흔들림·번쩍임 금지(`lessons.md`). 움직임은 `transform`/`scale`/`translate`/`opacity`만.

## 화면당 분량 (58)
한 화면에 읽을 글은 짧게: 큰 글씨 세 줄 + 자막 두 줄 정도. 더 필요하면 장면을 나누지 말고 문구를 줄인다.
